# Finance Her Way

A financial literacy coaching and research platform built with React and modern web technologies.

**Founder:** McKylee Mosby  
**Mission:** Closing the financial literacy gap through personalized coaching, practical education, and accessible resources.

## About This Site

Finance Her Way focuses on three key areas:
- **Minority Women:** Financial education and confidence-building
- **Small Businesses:** Financial guidance for sustainable growth
- **Nonprofits:** Research-driven financial support and strategies

## Getting Started

This is a static website hosted on GitHub Pages. Simply visit the live site to:
- Learn about Finance Her Way's mission
- Fill out research forms to help shape resources
- Connect with McKylee

## Technologies

- **HTML5 & CSS3** for structure and styling
- **React** for interactive components
- **Responsive Design** for mobile and desktop
- **Google Fonts** for typography
- **Bootstrap Icons** for UI elements
